Important! Without this file, kids can remove the extension from Firefox menu. This is critical for real protection.

Firefox policies required

For complete protection, install the policies.json file following the steps below. Without it, the extension can be removed from the browser.

Step 1: Download the file

Click the button below to download the policies.json file:

Step 2: Install the file
1 Open File Explorer as Administrator
2 Go to C:\Program Files\Mozilla Firefox\
3 Create folder named distribution
4 Copy policies.json into that folder
5 Restart Firefox completely
C:\Program Files\Mozilla Firefox\distribution\policies.json
1 Open Finder and go to Applications
2 Right-click Firefox and select Show Package Contents
3 Navigate to Contents/Resources
4 Create folder named distribution
5 Copy policies.json into that folder
6 Restart Firefox completely
/Applications/Firefox.app/Contents/Resources/distribution/policies.json
1 Open terminal
2 Run: sudo mkdir -p /usr/lib/firefox/distribution
3 Copy the file: sudo cp policies.json /usr/lib/firefox/distribution/
4 Restart Firefox completely
/usr/lib/firefox/distribution/policies.json
Step 3: Verify installation

After restarting Firefox, type about:policies in the address bar. You should see your policies listed.

File Contents (for reference) 
{
  "policies": {
    "BlockAboutAddons": true,
    "BlockAboutConfig": true,
    "BlockAboutProfiles": true,
    "BlockAboutSupport": true,
    "DisableDeveloperTools": true,
    "DisablePrivateBrowsing": true,
    "DisableSafeMode": true,
    "DisableProfileRefresh": true,
    "DisableProfileImport": true,
    "InstallAddonsPermission": {
      "Default": false
    },
    "Preferences": {
      "devtools.policy.disabled": true,
      "browser.privatebrowsing.autostart": false
    }
  }
}
Forgot my PIN?
Reinstall the extension to reset all settings including the PIN.
Extension was removed?
Install the policies.json file to prevent this. See "Lock Firefox" tab.
Child found a bypass?
Ensure: policies.json installed, child uses non-admin Windows account, settings are locked.
How to uninstall?
Delete policies.json first, restart Firefox, then remove extension from about:addons.
What gets blocked?
All non-whitelisted sites, private browsing, about:addons, developer tools, and Firefox support pages.
